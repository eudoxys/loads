# CLAUDE.md

Guidance for Claude when working in the `eudoxys/loads` repository.

## What this is

`loads` is a Python 3.12 package (alpha) that builds hourly, county-level US
electric (and non-electric) load models from public data sources, mostly for
the WECC region. It compiles sector loads (residential, commercial, industrial,
agricultural), predicts them for other years with a TSGAM time-series model
driven by weather, calibrates them to EIA energy data, and aggregates counties
onto network nodes (e.g. WECC240 busses).

- Docs site: https://www.eudoxys.com/loads (generated by pdoc from docstrings)
- Author/maintainer: David P. Chassin
- CLI entry point: `loads` → `loads.cli:main`

## Where things are

- `MANIFEST.md`: map of every file, a task index, and what not to read.
  Read it first instead of listing folders. Update it in the same PR that
  adds, moves, or deletes a file; `python .github/check_manifest.py` checks it.
- `DESIGN.md`: design, numbered decisions, planned modules, and the version 1
  open questions. Follow its decisions; ask before departing from one.
- General Eudoxys package conventions are in the `eudoxys-package` skill
  (`github.com/eudoxys/claude`).

Sibling eudoxys packages are core dependencies (installed from GitHub via
`requirements.txt`): `cache` (local data cache), `fips` (state/county lookups),
`weather` (NSRDB weather), `eia` (EIA forms 861/861m), `geohash`. The TSGAM
model comes from `tsgam_estimator` (github.com/nimish/estimator).

## Core conventions

**Data classes subclass `pd.DataFrame`.** Each accessor (`RESstock`,
`Residential`, `Commercial`, `Industry`, `Total`, `Calibrate`, ...) does all its
work in `__init__` and ends with `super().__init__(data)`. `Units` subclasses
`float` with `__new__`. Keep this pattern when adding a source.

**Cache-first loading.** Every expensive constructor follows this shape:

```python
if self.CACHEDIR:
    Cache.CACHEDIR = self.CACHEDIR
cache = Cache(package="loads", version=0, path=[state, county, "R.csv.gz"])
if cache.exists() and not refresh:
    try: data = pd.read_csv(cache.pathname, index_col=[0], parse_dates=[0])
    except Exception: data = None; cache.delete()
else:
    data = None
if data is None:
    ...build from source...
    data.to_csv(cache.pathname, index=True, header=True)
```

Each class has a `CACHEDIR = None` class attribute and a `refresh:bool=False`
argument. Cache file names encode the source (`R` residential, `C`
commercial, `T_...` total/training, etc.). Never write cache files into the
repo; `.cache*` is gitignored.

**`makeargs` classmethod.** CLI dispatch calls `Cls.makeargs(**vars(args))`,
which keeps only kwargs named in `__init__.__annotations__`. Any new
constructor argument the CLI should pass must be type-annotated, and its name
must match the CLI option's dest name (`state`, `county`, `year`, `building_type`).

**Column naming.** Columns are `{elec|nonelec}_{category}_MW` with categories
`baseload`, `cooling`, `heating`, `total`, `dg`, `net`. `Total` uses
`elec_{sector}_MW` (training data only; predictions return just the `X`
weather columns and the `Y` column). Invariants:
- `elec_total_MW = baseload + cooling + heating`
- `elec_net_MW = elec_total_MW + elec_dg_MW` and `elec_dg_MW <= 0`
  (DG is a negative load)
- weather columns: `temperature_degF`, `humidity_pc`, `global_Wpms`,
  `direct_Wpms`, `diffuse_Wpms`
Raw stock columns use `{fuel}_{enduse}` (`elec_`, `gas_`, `oil_`, `lng_`
(propane), `wood_`, `district_`, `other_`).

**Time index.** Hourly, tz-aware UTC, index name `timestamp`, 8760 rows for the
2018 reference year (8784 in leap years). RESstock/COMstock data is 2018 (AMY
2018); industrial/agricultural is 2019. `Total.TRAINING_YEAR = 2018`.

**Location arguments.** Most classes take `state` (two-letter code) and
`county` (name without "County", e.g. `"Alameda"`) and validate with
`fips.States()` / `fips.Counties()` asserts. `Estimator`, `Cluster`,
`clusters.csv` and `configs.csv` instead use a single `"County ST"` string
(e.g. `"Los Angeles CA"`).

**Building type codes.** Residential: `RSD RSA RSM RMM RMH`. Commercial codes
start with `C` (e.g. `CMO` medium office); see `COMstock.BUILDING_TYPES`.

**Missing data.** Some building types have no data in some counties; return a
zero frame and log at DEBUG rather than raising.

**Module `__main__` blocks** typically loop over all WECC counties
(`Counties(...).loc["WECC"]`) to (re)build the cache, honoring `--refresh` and
`--debug` from `sys.argv`. Run them as `python3 -m loads.<module> [--refresh] [--debug]`.

## Style

- 4-space indent, no spaces after commas in calls (`f(a,b,c=1)`), which is
  the house style; match it rather than reformatting.
- pdoc docstrings with dashed-underline sections: `Arguments`, `Returns`,
  `Examples`, `Caveats`, `References`, `Description`, as `  - \`name\`: text`
  bullets. Module docstrings carry usage examples with real output and often
  mermaid flowcharts; `$...$` math is rendered (pdoc `--math`).
- Prefix private helpers with `_` or mark them `"""@private ..."""` so pdoc
  hides them.
- Module-level `_logger = logging.getLogger(__file__)`; use `_logger.debug`
  for cache hits/misses.
- Pylint is run in CI (`--fail-under 0`, so informational); use targeted
  `# pylint: disable=...` comments the way existing code does.
- Don't reformat untouched code or reorder imports in unrelated edits.

## Build, test, docs

```bash
python3.12 -m venv .venv && . .venv/bin/activate
pip install --upgrade pip && pip install -e . pytest
pytest loads/_test                  # tests (network + NSRDB credentials needed)
cd loads && pylint *.py             # lint as CI does
make docs                           # pdoc → ./docs (creates its own .venv)
```

- Python is pinned to `==3.12.*`.
- Tests and most constructors download from NREL/OEDI S3, Census, OpenEI and
  NSRDB on first run and can take many minutes. Weather needs NSRDB
  credentials in `~/.nsrdb/credentials.json` (CI writes it from the
  `NSRDB_CREDENTIALS` secret).
- CI: `.github/workflows/validate.yaml` (pip install, pylint, pytest on
  push/PR to `main`); `deploy-pages.yaml` runs `make docs` and publishes
  `docs/` to GitHub Pages on push to `main`.

## Known rough edges (don't "fix" silently; mention or ask)

- `Makefile` `test` target runs `./test/test.sh`, which doesn't exist; tests
  live in `loads/_test/`.
- `help`/`info` reference undefined `webbrowser` and `_URLS`; `viewer`/`test`
  point at `viewer.py`/`tests.py`, which aren't in the package; there's a
  duplicate `viewer` case. `_plot`/`_getdata` use `case "_":` (a string
  literal) instead of `case _:`, so `plot` draws nothing for the sector
  datasets.
- `Total` has no year argument; the CLI's `-Y` only reaches `Weather`, and
  `Total`'s `dg` and `holdout` arguments are unused. `Total` imports `DG`
  but doesn't use it (training DG comes from RESstock/COMstock PV).
- `dgen.SolarModel` has a stray `print(len(weather.index))`; `dgen.compile`
  has debugging `print`/`quit()` calls that stop it before writing; the
  `SolarModel` branch of `DG` uses undefined names. `wecc/county_dg.csv.gz`
  holds positive DG output, opposite to the `elec_dg_MW` sign convention.
- `Energy` requires a list/tuple `year` (the cache name uses `min(year)`),
  its cache ignores `counties`, and a failing county appends the previous
  county's result.
- `EstimatorConfig.outlier_regularizer`/`outlier_threshold` lack annotations,
  so they are class attributes, not `NamedTuple` fields; the threshold is
  never applied (`TODO` in `_get_model`).
- `tsgam_evaluate.py` writes `tests/test_config.csv` but then reads
  `tests/best_config.csv`. It and `Total`'s `__main__` use the gitignored
  `tests/` scratch folder; the checked-in cluster files are
  `loads/clusters.csv` (current `elec_total_MW` k=6 medoids) and
  `loads/configs.csv` (TSGAM configs for an earlier medoid set).

## Working rules

- Don't commit large generated data (cache files, `*_errors.csv`,
  `*_test_*.csv`, `tests/`, `tsgam_test/` are ignored). Checked-in CSVs under
  `caiso/`, `isone/`, `wecc/`, `clusters.csv`, `configs.csv` are curated
  inputs; regenerate them only when asked.
- When changing a public class's columns or arguments, update its module
  docstring example and the README example output.
- Avoid triggering full-WECC rebuilds unprompted; they take hours. Test on a
  single county (Alameda CA is the conventional example).
